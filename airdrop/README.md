# VIRIO Early Community Distribution Documentation

These documents describe the Base-first, participation-based 100M VIRIO community bootstrap:

- [Overview and allocation](01-overview-and-allocation.md)
- [Qualification and contribution points](02-qualification-and-points.md)

The release is a 10M genesis claim plus a 90M participation stream from month 3 through month 24. Fee distribution, transferable stVIRIO and buyback mechanisms are separate proposed functionality and disabled at genesis pending security approval.
